# 实际回答

从JT叔叔讲庄子的这套读法来看，你这里最值得检查的，可能是一个等号：**“我比同事强，才证明我是有价值的人。”**如果这个等号成立，工作里的批评就很容易被听成：“你不够好，你没有资格安心地待在这里。”于是，你想做好的已经不只是这件工作，还要赶紧挽回对自己的判决。

这是我对你这两句话的一个候选理解。你可能很喜欢自己的专业，也可能担心晋升、收入或被淘汰；这些需要各自看清，不能仅凭“好胜”就把你归成某种人。JT这套心法能帮我们做的，是看看真实的兴趣和现实需求，在哪里被“我必须胜过别人”的要求绑住了。

JT在《庄子基本功》里把“我感觉得到自己存在”的self，与那个爱面子、要认同和掌声的ego分开。丧我，就是把后者里面的“我应该”“别人应该”一条条拆开，让真实的自己有机会被听见。放到你这里，先拿出来检查的可以是：“我应该比他们快。”“有本事的人不应该被批评。”“别人应该看得出我更强。”它们听起来很自然，却未必是事实，也未必服务于你想过的人生。（《庄子基本功》，PDF第25–29页）

JT有一个特别贴近你的例子：他认识一个同事，只要听别人说“我也会”，就会炸，因为他希望只有自己会。那句话本来只提供了一项信息——另一人也具备这项能力；被额外加上的，却可能是“我的特别被夺走了”。这是我对这个例子机制的理解，JT则用它说明，人身上会有各种“按钮”。他紧接着又说，找按钮并不是修炼全部的重点；重要的是增长心力，让自己有能力看见、修改信念，而且这也不是百分之百正确的心灵模型。（《内七篇课程》，PDF第148页）

你可以借这个例子辨认：同事做得好时，你难受的究竟是什么？是他真会影响你的工作机会，还是“原来我不是唯一厉害的人”？前者需要看岗位、成果和组织的实际安排；后者则值得问：**为什么另一人有本事，会变成我没有价值的证据？**

JT讲自己与金城武同班之后，对长相很自卑。朋友却提醒他，拿金城武当比较标准，本身就很狂傲。JT用这个故事说，自我感觉良好和不良好，常常被一把随意设定的尺控制。放到工作里，你可以把“强”拆开：谁在哪项任务上更熟练，谁更擅长协调，谁这次判断得更准。这些都可以具体认识；把不同的能力合成一个“谁整个人比较好”的总排名，那个排名就开始吞掉事实了。（《内七篇课程》，PDF第39–41页）

课程临近结束，JT又读到阳子居问老子：一个反应灵敏、很能干、学习不倦的人，能不能当明王？JT把老子的回答解释为：技术能说明你可以被雇来做事，却不等于自在；如果存在价值全绑在功能上，就会劳累、心慌。他在这里还回头承认，自己前面讲功能性的讲法也不对，人被绑在功能性上很可怜。这给你的问题补了一层：提高能力、获得报酬，都有实际意义；可如果“有用”和“比别人更有用”成了你唯一能安心存在的条件，越能干，也可能越放不下证明。（《内七篇课程》，PDF第1423–1424页；最后这句是我对职场处境的应用。）

更深的一层，是JT讲的**“无意识的自我辩论”与“假力”**。

他描述过一种结构：心底有“我很差”“我不值得”的声音，于是每句话、每件事都要证明自己聪明、优秀。看起来很上进，实际的动力却一直围着那个负面判决转。一次赢了，暂时松一口气；一次被批评，整个判决又回来了。JT认为，用行为不断反证自己“不够好”，会让这场内战继续得到力量。（《内七篇课程》，PDF第303–306、320–326页）

他自己也掉进过这里。他本来因为喜欢读中医，拉朋友开读书会，慢慢有人愿意付钱听，他觉得很享受、也很感谢。后来，听到“你帮助了很多人”的赞美，他又开始多开班、多工作，想证明自己值得存在。他最难辨认的，是自己本来就爱教书，所以分不清多开一班究竟来自喜欢，还是来自“我不多贡献一点，就不够格”。后来他停下来，在家做饭、过普通生活，最初仍会害怕，却逐渐有了较好的心情。（《内七篇课程》，PDF第431–440页；其中病倒及其因果解释是JT的个人自述，不能由此推出心理信念决定疾病。）

这个例子对你有用的地方，是：**真实热爱和自我证明可以混在同一份努力里。**不用立刻否定所有上进心。可以辨认每次想再多做一点时的滋味：你在想“这问题真有意思，我想做得更准确”，还是在想“不能让他们觉得我输”？后者出现，也不必马上加一句“我怎么这么虚荣”。否则，“我必须显得优秀”又变成“我必须显得很会庄子”，内战只是换了题目。

JT从宋荣子讲的“情绪独立”，很适合接在这里。庄子原文说：“举世而誉之而不加劝，举世而非之而不加沮。”JT解释为，赞美不会自动使你加码，否定也不会自动使你撤掉自己的方向。要能分辨，别人的认同属于外面，自己真正要做什么，是需要自己认清的。（《内七篇课程》，PDF第42–44页）

他曾在儿童庄子班画漫画，一位妈妈说画得有趣、以后多画一点，他马上动念想多画——他就拿自己这一下当“加劝”的例子。你的功课也包含这一面：被夸之后，是否马上要再表现一轮、保持“最强”的位置？赞美与批评，如果都能替你决定下一步，你的工作方向就一直被评价牵着走。

在职场里应用这一点，我的理解是：你仍可以认真听批评，把其中能验证的工作信息拿进来；同时，逐步松开“你必须认可我这个人”的要求。主管确实可能影响你的岗位和收入，这些现实影响需要处理。谁说得对、有没有误会，也需要求证。情绪独立要长出来的，是在这些事实中仍能选择怎样做，而不是被一句评价推着抢救面子。

JT讲《达生》时，有两幅很好的画面。

一幅是斗鸡。它最初虚骄、逞强，后来仍对声音和影子反射，再后来还全身紧绷，随时准备对抗；直到别的鸡叫，它也能安定，才算接近练成。JT把前面的派头读成代偿：一直亮出“我很强”，不等于心里已经安稳。用在你这里，比较好的变化可以是：别人展示能力时，你还听得进去；别人指出问题时，你还看得清。这个寓言不能保证淡定就能使现实中的恶意消失，也不要求你忍受不合理对待。（《内七篇课程》，PDF第641–645页）

另一幅是梓庆削木做乐器。JT讲他先放薄赏赐、地位，再放薄同行的评价与做得巧不巧的得失，接着才去树林，看哪块材料确实能成器；找不到合适的，就不硬做。这里很重要的顺序，是清掉自我得失，才能更客观地认识材料。放到工作里，你要看的“材料”可以是任务的真正目标、现有信息、时间、自己的能力和同事的长处。少一点“我要让你们看见我”，才有更多心力给它们。（《内七篇课程》，PDF第665–671页；这里的斋戒不需要照字面实行断食。）

JT还用同一项技术、赌瓦片与赌黄金表现不同的寓言，解释“外重者内拙”：注意力压在外面的得失上，本来会做的事也会变钝。他对做豆浆的助教说，要看手里的豆浆，别一直看老师的脸色。这句话在你的情境里可以变成：收到反馈后，先回到“这个成果哪里还没好”，而不是马上回到“他现在觉得我是什么人”。（《内七篇课程》，PDF第614–618页）

这也需要连着JT另一面来读。他要求助教自己品管豆浆：别人没有责怪，不等于自己做得好了。少依赖评价之后，仍要对实际成果负责。真力可以很认真，也可以包含辛苦；JT明确说，为了喜欢的教学，他愿意花时间备课，读书当时未必快乐，但他知道优先顺位，愿意承担。（《内七篇课程》，PDF第395、448页）

下一次被批评时，可以只做一个小实验：

1. **先停一轮证明。**留意自己是否急着补上一句“可是我比他做得多”“你怎么不看看别人”。暂时不追加这一轮较量。必要时说：“这一点我记下了，我先核对一下具体情况，再回复。”这一步对应JT说的先中止辩论行为，让新的信息有机会进来。（《庄子基本功》，PDF第78、96–106页）
2. **把三样东西分开写。**已知事实：对方实际说了什么，成果哪里有问题；我以为：他看不起我、大家都觉得我差；我希望：他承认我更强、批评别当着别人讲、给出明确标准。后两栏不是一写下来就要消灭，先看见自己加进了什么。对方的动机不知道，就保留不知道。
3. **问这一刀怎么下才中肯。**如果确有失误，具体改哪一处；如果标准含糊，问清怎样算做好；如果是误会，清楚说明事实；如果表达方式造成实际困扰，另谈沟通方式。JT的庖丁心法是看准缝隙，不用一个“我都错了”替代认识。（《庄子基本功》，PDF第71–75页）
4. **做一件无需排名也值得做的小事。**例如把一段说明写清、学会同事的一项方法、把自己喜欢的一项分析做准确。如果很羡慕某位同事，分别写出你想学的长处与不想采纳的行为。JT谈嫉妒时也这样拆：喜欢的优点可以发展，讨厌的缺点不用一起吞下。（《内七篇课程》，PDF第1312–1313页）

复盘时，看自己有没有更准确地听懂、有无完成该做的修正、有没有少花一点力气在总排名上。也可以诚实发现：“我这次仍想证明自己，但已经没有追加那句争辩。”这种具体变化，比给自己一个“境界很高”的新称号更有用。

最后要守住JT自己强调的界线：反省从同情自己的苦开始，找怎样不再反复伤自己；自责则在继续判自己有罪。受批评会难受这件事，可以先承认，随后慢慢识别背后的要求。JT说自己刚开始处理一个情绪，会花三五天乃至两周；课程里也接受忙碌的学生隔一两天、平静后再回看。（《庄子基本功》，PDF第94、109–113页；《内七篇课程》，PDF第1306–1307页）

他在最后一堂课还专门澄清：自己不爱听诉苦，并不代表别人不应该诉苦；反省时也要让自己知道，自己在不开心、烦恼、委屈。若把“人应该静、应该平”变成不准有负面感受，就可能压抑了。接着他把课程收束到尊重自己的内在小孩，以及让身边的人能真实、平等地交流。沿着这个方向，我会建议你先听见：“我很怕被看低，我现在确实难受。”需要时，也可以在双方愿意的情况下找人谈谈。听见以后，才有空间看哪个期待让自己更苦，下一步怎样对自己和工作都更中肯。（《内七篇课程》，PDF第1451–1454页；寻求双方自愿的支持，是我的应用，不是照搬JT个人的倾听偏好。）

你可以给自己留下这样的余地：今天这件事确实暴露了一项不足，我把它补好；同事确实有一项能力比我好，我可以看清、也可以学习。与此同时，我还在慢慢认清，自己愿意把这份工作做成什么样，怎样做会让自己的生命更充实。让这些事实有位置，“必须一直比别人强”的那个声音，才有机会不用独占整颗心。
