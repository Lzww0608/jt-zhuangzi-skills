# 从《内七篇》的论证进入个人问题

这是解释规程。每次回应个人问题时读取；在完成全体系导航与有关原文阅读后使用。它规定怎样把读到的材料变成解释，不替代原文，也不是给用户套的心理诊断表。

核心任务是：让JT所讲的庄子改变我们怎样理解这件事。若用户经验支持自我维持的循环，指出一个具体内心动作为什么越用力越困住自己，以及另一种接触事实、感受和行动的可能如何出现；若不支持，就说明实际难处与此处心法的作用，不强造反作用。仅用书中的话支持“核实信息、接受自己、做好准备”，还没有完成这个任务。

## 一、以课程论证为主干，《基本功》作全体系对照

《基本功》提供浓缩符号、练法关系和回查入口；《内七篇课程》保留概念怎样出现、为什么需要它、前一步为何还不够、例子怎样翻转和后来的修正。默认个人问题的**主要解释链应由有关课程原段承担**，再用《基本功》对照练法、次序和限定。不能因为《基本功》先通读完，就让它的短结论替代课程的展开。

先明确真正使用的篇章。课程文件虽名《内七篇》，还含《渔父》《达生》：豆浆、斗鸡、梓庆和怕影恶迹可以深化解释，但不能把它们说成内七篇原寓言。涉及内七篇的相关问题，先查有关内篇怎样形成问题与解法，再接补充篇；没有贴合的连接时如实说明所用是补充篇，不硬塞七篇名句凑覆盖。

篇章入口供选路，内容仍须读原讲：

| 论证所要解决的问题 | 课程入口 | 应重建的关系 |
|---|---|---|
| 别人的誉非决定心情、社会尺度决定我是否有价值 | 《逍遥游》03–08讲 | 相对幸福、宋荣子、材与不材、无用的推进；境界描述怎样与入门练习区别 |
| 一受触动就防御、未来剧情、内心争输赢 | 《齐物论》09–18、23讲 | 人籁／孔窍→自我信念群→为何黏住它→成心／守胜→道枢／环中；暂停反扑为何让资讯进来 |
| 技艺、过度用力、做好以后又索取认可 | 《养生主》36–40讲 | 生命主轴、庖丁中肯／因循、复杂处谨慎、踌躇满志；技艺所得怎样回到事本身 |
| 强权或关系中受夹、救人欲、把内在听成读心 | 《人间世》47–60讲 | 心斋前置、气听校准、命义与份位、不从恶、支离其德；可选与不可选的条件 |
| 完美形象、存在感、可爱与幸福 | 《德充符》61–70讲 | 止水／明镜、才全德不形、长德忘形、无情；形象如何遮住真实生命，结果为何不能命令实现 |
| 害怕失去、内心黑暗、死生、修行跳级 | 《大宗师》71–90讲 | 好恶、潜在意识、真人、撄宁、坐忘的次序；包括晚段对苦难与创造实相的自疑 |
| 师生或亲密关系的主权、救人、控制与功能 | 《应帝王》91–94讲 | 份位与能力、无事生定、各自人生；功能论改口、内在小孩与收束回基本功 |

## 二、先重建原文怎样走到结论

选择与此事最有关的一条主线。深入分析个人困惑时，至少把最贴合的核心一讲读完，即使事件描述很短，并追到必要的下一讲承接或同主题修正。课程一次显示约8页，长讲拆批；按页内标题边界判断讲尾。不以“引用了几页”代替整条论证。若主线涉及不同篇，读各自完整段落及必要反向材料。

在工作笔记中分别写出以下内容，不能把论证和例子合并成“有个故事”一栏：

1. **原问题**：庄子／JT在这里要解释什么难题？例如已经知道观念可以换，为什么一被触动仍紧抱原观念。
2. **通常的解法怎样起作用**：若原文在讲争赢、先讨认可、拼命做善事、把恐惧压下等动作，辨它给了哪种暂时所得、又怎样维持原要求；与用户经验核对，不能预设他的做法必有反作用。努力、善意和风险准备本身都可以合理。
3. **论证推进**：原词或寓言承担什么作用？JT怎样把它转到信念、心力、感知／表现、代偿或份位？其中什么是他的个人世界观、外借框架或推测。
4. **转折与改变关节**：哪一步改变后，原结构不再必须继续？例如暂缓第一句反击，原先听不见的信息才可能进来；认出自己未核实的承诺，才不用把对方编成辜负者。
5. **范围和张力**：原段有哪些前提、反例、尚未知与后段改口？它们可能使我们换主解释，不能只加一句免责声明后仍照用。

JT课程125–138页本身给了这种推进：从晚饭／公车／生意伙伴三个确定程度，提出越不确定是否越需争赢；再讲表面意识的不完整，区分承认不知与以战斗补不安；最后说明练习是扩大心的容量。若只摘“不要辩论”，就失去整条理由。131–132页的灵魂／潜在意识模型属于JT的转译，不冒充庄子逐字心理学或已验证事实；140页他也自嘲自己的转码。日常分析可看不完整如何被处理，而不保证任何超常感知。

## 三、贴住一个具体片刻，辨认内在的运作

先选用户实际给出的片刻：收到谈话邀请、听到一句批评、决定接下一项任务、看到父母消息等。把以下环节当作待核对的线索，缺少证据就留空，不能编满六格：

**发生了什么 → 我马上把它听成什么 → 身心怎样反应 → 我想立刻做什么 → 这样做暂时保住什么 → 做后怎样反过来加深原来的解释。**

例如“怕领导谈话”不是终点。可以进一步辨认：未知结果是否被填成领导已经不满意；心里是否先准备自辩；慌是否又被自己当成事情一定不妙的证据。课程140–141、150–151页给了信念回圈与未来预演的依据，但这个用户是否走了每一跳仍需确认。导师友好可能是真信息，也可能被滤掉；若用户未说后者，不把它写成事实。

解释即时所得时保持尊重。旧做法可能曾让人安心、免于冲突或取得实际好处；“我执”“代偿”不是对人的辱骂。课程191–192页也说明幼年相信父母万能曾有用，成年时才可能需要置换。深入不是嘲笑原来那个自己。

**不是每次害怕都在维护面子，不是每次尽责都在赎罪，不是每次愤怒都为争赢。** 区分岗位能力、生计代价、被认可的愿望、理想自我受损和存在资格判决。若目前只知道有经济风险，就以此为实际重量；不能从“第一份工作”直接推出“童年不被爱”。反之，若用户认出成绩只能短暂压住不配的感觉，也不能用“这只是现实压力”跳过它。

## 四、让解释能够被事实纠正

为主要解释保留一个实质不同的候选，并说明什么事实会改变判断。不是每个回答都列假设表，而是在推理中真正给另一路活路。

| 当前解释 | 有什么可区分的经验 | 怎样调整 |
|---|---|---|
| 害怕尚未知的谈话，头脑编成已被否定 | 若领导已有具体未达标反馈，未知范围已经缩小 | 改为承认真实问题与影响；仅未确定的部分仍谈“虑” |
| 把岗位评价当成整个人的价值判决 | 用户明确说并无该等号，只怕收入断档 | 撤回价值判决主线，回到实际生计与尚未知的结果；不能继续解释他其实不配 |
| 越被夸越要证明，是认可型代偿 | 用户能完成后停下，也接受局部失误，额外投入因真实喜欢 | 保留热爱／责任解释，不将高投入本身病理化 |
| 争辩是在护旧观念 | 对方有错误事实且会损害正式评价，用户只想作一次有限澄清 | 支持澄清与协商；观察是否仍非要得到彻底认同，勿要求沉默 |
| 付出是补偿不爱、要对方还债 | 存在明确交换、照护需求、自愿投入且有满足 | 保留公平、同理与责任；不把辛苦单独当成没有爱 |

用户否认候选时，不用“你还没意识到”维护解释。可以重读其他篇或修正应用，也可以承认现在资料不足。停止由我以为吞没感知力，同样适用于分析者。

## 五、讲清丧我所松开的是什么，感知怎样回来

《齐物论》116–124页并非只说“不靠别人评价”。JT用孔窍解释事件如何变声，并区分self与ego：被拆换的是由观念纠缠形成的反应程式；觉知、真实好恶、感知和表现要能保留下来。后续125–141页则问为什么程式不肯松，回答不安、守胜和资讯过滤怎样互相维持。

因此“让想法只是尚未核实的想法”，其意义不仅是把坏想法替换成好想法，而是旧观念不再独占解释权，另一些实际信息和真实需要才进得来。松开“这次必须证明我从不会错”以后，才可能看清哪一处会、哪一处不会、想怎样学、是否适合这份岗位。改变是接触事实的能力增加，不是强行把自己劝成乐观；好坏结果仍可能发生。

JT还保留潜在意识／彼岸主导、更完整的自我与生命愿景这层世界观。需要它时按原文说明归属及功法次序，不把全部体系削成思维纠错，也不拿彼岸或灵魂给用户判命。特别是气听：728–729、733–734页要求向内清理与承认不知，不能把“我听到老板语气不对”封成高级气听。

## 六、练习必须落在刚解释过的改变关节

选一处可承担的小动作，说明它为什么介入这里，及怎样知道读法是否合适。可以整理事实、问反馈、表达界线；但不能把一长串通用工作方法拿来代替已经承诺的内心分析。

例如未来预演的练习，关注的是**什么时候我又从不知道跳成知道，以及我能否带着尚未消失的怕停止续写剧情**。担心笔记本来自课程150–151页；问mentor只是获得有限信息，不会使整个未来确定。准备完仍怕时，也不要以无限补材料换绝对安心。这里的“先容许未知→有界准备→仍容许未知”是助手应用，不是JT原列三步法。

若主线是成心与评价，练习可看第一次反击前是否容下新信息；若主线是真实失误，就查具体误估、认错并修一项实际行为；若主线是赎罪型加码，则在不损害责任的范围内暂不追加一项证明，观察它引起的恐慌与实际后果。三种练习不能写成同一份三栏表就算完成。

再看旧结构如何挪用练习：“我必须表现淡定才算懂庄子”“停辩是让领导最终更认同我”“承认不知也必须马上不怕”都可能重新以表现赢认可。不要因此禁止练习，而是辨认其动力后减去那项考试。课程156页还保留趁未很怒早表达界线，与128页暂缓反扑一起读；不把停止动作误写成压抑感受。

把125–128、140–141页的停止对外拗辩，连接到133、150–151页的未来预演，是有来源依据的助手应用。应说明停止的是追加的想象应战、证明或无限求保证，不能把害怕本身、正常思考和有用规划都叫作辩论。若用户只是在作有限准备，没有这类追加，就不要求他停掉准备来证明丧我。

## 七、心理深度的界限与作答完成标准

课程142–143页，JT明确说庄子的练法并不要求由每个情绪倒推信念、刨根到每个起源；课堂也不能替每个人整理其排列组合。148页他承认按钮不是全部重点、模型未必百分之百正确，仍须练感知／表现与意识的心力。我们的具体分析是有来源的助手应用，不能把挖遍根源封成庄子必须完成的修行。

回答不用套机械栏目，但实质上需完成：

- 有一条由相关课程原段推进的解释，说明此处的难处与改变关节；若存在自我维持的循环才展开其反作用，不强造。准确说明目前不足以认定更深动机也是完成解释；《基本功》提供对照而不是顶替。
- 用用户的具体事件辨认内在时序；哪些已知、哪些候选、哪一跳没证据清楚可见。
- 以一个贴合原例解释动作与转折；若原例不适合，宁可说明原因，不把人物／条件换掉强凑。寓言、JT自述和助手迁移分别归属。
- 真正容许不同事实改变主判断；现实岗位、费用、照护、伤害或技能问题在解释内部起作用，而不只在段尾被安慰一句。
- 练习对应改变关节，也说明可能被旧要求挪用的方式；不以压抑、自责或控制他人收尾。

最后做一个自检：去掉书名与术语后，是否只剩适用于任何事的安慰与清单？若是，补回原文的论证和此人此刻的过程；增加引文、心理名词、玄学术语或页数不能替代。**这个自检是启发式，不意味着必须写术语才算深。** 如果白话已清楚说明JT这条论证及其具体介入点，就已达成目的。

工作评价、加码证明与愿景摆荡的完整材料另见[课程机制细读](course-work-mechanisms.md)。它是重建论证的示范资源；不在所有问题中默认灌输这三条机制，更不照抄转正案例来覆盖用户的新事实。
